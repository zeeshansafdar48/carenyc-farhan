# Fonts

The site loads these `.woff2` files (see `src/styles/_fonts.scss`):

| File                        | Typeface / weight             |
| --------------------------- | ----------------------------- |
| `AvenirLTStd-Roman.woff2`   | Avenir LT Std 55 Roman (400)  |
| `AvenirLTStd-Medium.woff2`  | Avenir LT Std 65 Medium (500) |
| `AvenirLTStd-Heavy.woff2`   | Avenir LT Std 85 Heavy (800)  |
| `Butler-Regular.woff2`      | Butler Regular (400)          |
| `Butler-Medium.woff2`       | Butler Medium (500)           |

The `.woff2` files were converted from the `.otf` originals in this folder. If a font
is replaced, convert the new `.otf` to `.woff2` and keep the same file name.

Text positions in the components are tuned to these fonts' metrics
(Avenir: ascent 0.756, cap height 0.708; Butler: ascent 0.735, cap height 0.704).
